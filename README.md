# The Ninth Tide — Releases

Public download and automatic-update feed for **The Ninth Tide**.

## Download
- [Windows Installer](https://github.com/SPORstudio-Official/THE-NINTH-TIDE-RELEASES/releases/latest/download/The-Ninth-Tide-Windows-Installer.exe) - single portable EXE
- [Android Installer](https://github.com/SPORstudio-Official/THE-NINTH-TIDE-RELEASES/releases/latest/download/The-Ninth-Tide-Android-Installer.apk) - signed APK

The Windows build checks this repository for updates and verifies every download with SHA-256 before installing it after you quit. Android updates are installed manually over the existing app; saves stay intact. No account is required. The source code is private.
